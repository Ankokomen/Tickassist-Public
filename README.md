# TickAssist

TickAssist is a local ticket-handling tool for Planmeca support: a note
generator with connections to CXone MAX, Dynamics 365 and Google Sheets. It
runs on your own PC as a small web page; nothing is installed system-wide and
no administrator rights are needed.

## Install

1. Download **Install-TickAssist.bat** from the
   [latest release](https://github.com/Ankokomen/Tickassist-Public/releases/latest).
2. Double-click it.

It installs for your Windows user, adds Start menu and desktop shortcuts, and
needs no network and no administrator rights. Running it over an installed
copy replaces the program and keeps your settings, lists and macros.

## Update

TickAssist checks for a newer version whenever it opens and offers it in the
top bar (Settings > Updates). A copy older than 6.4 has to be moved over once
by running the installer above.
